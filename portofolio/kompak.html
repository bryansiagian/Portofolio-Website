OverviewRingkasan

Kompak is a web application designed to make university group assignments easier to coordinate. Instead of losing important tasks in messaging threads, students can create shared workspaces, organize projects on Kanban boards, assign responsibilities, and follow updates together in real time. The interface is designed around Indonesian-first workflows and mobile usability.Kompak adalah aplikasi web untuk mempermudah koordinasi tugas kelompok mahasiswa. Daripada kehilangan tugas penting di percakapan chat, anggota dapat membuat ruang kerja bersama, mengatur proyek pada papan Kanban, membagi tanggung jawab, dan mengikuti perubahan tugas secara real-time. Antarmukanya mengutamakan bahasa Indonesia dan kemudahan penggunaan di perangkat mobile.

The Problem & SolutionMasalah & Solusi

Group assignments are often coordinated through chat applications, where instructions, decisions, and task ownership become difficult to track. Kompak brings essential collaboration tools into a simpler workflow: create a group, invite classmates through a shareable link, split a project into tasks, and track changes from a shared board.Koordinasi tugas kelompok sering berlangsung melalui aplikasi chat sehingga instruksi, keputusan, dan pembagian tanggung jawab sulit dilacak. Kompak menyatukan kebutuhan kolaborasi ke dalam alur yang lebih sederhana: buat kelompok, undang teman melalui tautan, pecah proyek menjadi tugas, lalu pantau perubahannya melalui papan bersama.

Key FeaturesFitur Utama

  • Group and project workspaces with member roles and shareable invitation links, including WhatsApp sharing.Ruang kerja kelompok dan proyek dengan peran anggota serta tautan undangan yang dapat dibagikan melalui WhatsApp.
  • Kanban boards with customizable columns, task creation, drag-and-drop ordering, and non-drag task movement.Papan Kanban dengan kolom yang dapat diatur, pembuatan tugas, drag-and-drop, dan alternatif pemindahan tugas tanpa drag.
  • Real-time task and board synchronization using Socket.IO, with optimistic updates and rollback on failure.Sinkronisasi papan dan tugas secara real-time dengan Socket.IO, termasuk optimistic update dan rollback ketika terjadi kegagalan.
  • Task details, labels, filters, comments, activity history, and project/workspace search.Detail tugas, label, filter, komentar, riwayat aktivitas, serta pencarian di proyek dan ruang kerja.
  • AI-assisted subtask suggestions and discussion summaries integrated through a server-side LLM service.Saran subtugas dan ringkasan diskusi berbantuan AI melalui layanan LLM pada backend.
  • Email verification, session management, role-based permissions, and responsive Indonesian-language UI.Verifikasi email, pengelolaan sesi, hak akses berbasis peran, serta UI responsif berbahasa Indonesia.

System ArchitectureArsitektur Sistem

A TypeScript monorepo separates the Next.js interface, NestJS API, and shared request/response schemas. REST handles writes while Socket.IO broadcasts changes to collaborators. Prisma manages access to PostgreSQL. Authentication and AI integrations run server-side.Monorepo TypeScript memisahkan antarmuka Next.js, API NestJS, serta skema request/response bersama. REST menangani perubahan data, sedangkan Socket.IO menyiarkan pembaruan kepada anggota lain. Prisma mengelola akses ke PostgreSQL. Autentikasi dan integrasi AI berjalan pada sisi server.
