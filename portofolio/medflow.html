OverviewGambaran Umum

What is MedFlow?Apa itu MedFlow?

MedFlow is a real-time public transportation tracking system built for Medan, Indonesia's third-largest city. The app targets the city's angkot (minibus) network — a network that operates with no digital infrastructure, no schedules, and no predictability for daily commuters.

MedFlow adalah sistem pelacakan transportasi umum real-time yang dibangun untuk Medan, kota terbesar ketiga di Indonesia. Aplikasi ini menyasar jaringan angkot (angkutan kota) — jaringan yang beroperasi tanpa infrastruktur digital, tanpa jadwal, dan tanpa kepastian bagi penumpang sehari-hari.

The system tracks vehicle locations live using GPS data fed through a Laravel REST API backend, visualized on a Flutter mobile app using Google Maps. Users can see which angkot is nearby, how far away it is, and which route it's running — information that simply didn't exist before in any accessible form.

Sistem ini melacak lokasi kendaraan secara langsung menggunakan data GPS yang dikirim melalui backend Laravel REST API, lalu divisualisasikan di aplikasi Flutter menggunakan Google Maps. Pengguna dapat melihat angkot terdekat, jarak tempuhnya, dan rute yang sedang dilalui — informasi yang sebelumnya tidak pernah tersedia dalam bentuk yang mudah diakses.

Beyond tracking, MedFlow integrates real-time weather data from the OpenWeatherMap API to give trip recommendations. If it's raining heavily, the app can suggest alternatives or flag potential delays. The project was built for the Medan Coding Competition 2026, where it was awarded 2nd place.

Lebih dari sekadar pelacakan, MedFlow mengintegrasikan data cuaca real-time dari OpenWeatherMap API untuk memberikan rekomendasi perjalanan. Jika hujan deras, aplikasi dapat menyarankan alternatif rute atau menandai potensi keterlambatan. Proyek ini dibangun untuk Medan Coding Competition 2026 dan meraih Juara 2.

Problem & SolutionMasalah & Solusi

The gap MedFlow fills.Celah yang MedFlow isi.

⚠️
The ProblemMasalahnya
  • Medan's angkot network has no digital presence — no app, no schedule, no real-time location data. Passengers wait with no idea when the next vehicle arrives.
  • Jaringan angkot Medan tidak memiliki kehadiran digital — tidak ada aplikasi, tidak ada jadwal, tidak ada data lokasi real-time. Penumpang menunggu tanpa tahu kapan kendaraan berikutnya tiba.
  • Routes overlap and change informally, making it nearly impossible for newcomers or occasional riders to know which angkot to take.
  • Rute saling tumpang tindih dan berubah secara informal, sehingga hampir mustahil bagi pendatang baru atau penumpang sesekali untuk mengetahui angkot mana yang harus dinaiki.
  • No weather integration — commuters get caught off guard by Medan's sudden heavy rains, with no way to plan their route proactively.
  • Tidak ada integrasi cuaca — penumpang kerap kaget dengan hujan deras mendadak khas Medan, tanpa cara untuk merencanakan rute secara proaktif.
  • Medan's Smart City aspirations lack a transportation layer. Without data, city planners can't optimize routes or understand demand patterns.
  • Aspirasi Smart City Medan tidak memiliki lapisan transportasi. Tanpa data, perencana kota tidak bisa mengoptimalkan rute atau memahami pola permintaan.
✦
Our ApproachPendekatan Kami
  • Built a GPS-based vehicle tracking backend in Laravel that receives location updates from angkot driver devices and exposes them via REST API to the mobile app.
  • Membangun backend pelacakan kendaraan berbasis GPS di Laravel yang menerima pembaruan lokasi dari perangkat pengemudi angkot dan mengeksposnya melalui REST API ke aplikasi mobile.
  • Designed a Flutter app with Google Maps integration showing live vehicle positions, route paths, and estimated arrival information.
  • Merancang aplikasi Flutter dengan integrasi Google Maps yang menampilkan posisi kendaraan secara langsung, jalur rute, dan estimasi waktu kedatangan.
  • Integrated OpenWeatherMap API to overlay current and forecasted weather on trip planning, so users can make informed decisions before leaving.
  • Mengintegrasikan OpenWeatherMap API untuk menampilkan cuaca saat ini dan prakiraan dalam perencanaan perjalanan, sehingga pengguna bisa mengambil keputusan sebelum berangkat.
  • Used OpenStreetMap (OSM) and OSRM for open routing data, keeping the system independent of expensive proprietary map APIs for routing calculations.
  • Menggunakan OpenStreetMap (OSM) dan OSRM untuk data routing terbuka, menjaga sistem tetap independen dari API peta proprietary yang mahal untuk kalkulasi routing.

FeaturesFitur

What the app does.Apa yang bisa dilakukan aplikasi ini.

📍
Live Vehicle TrackingPelacakan Kendaraan Langsung
See angkot positions updated in real-time on an interactive map. Know exactly where the nearest vehicle is and which direction it's heading.
Lihat posisi angkot yang diperbarui secara real-time di peta interaktif. Ketahui persis di mana kendaraan terdekat berada dan ke arah mana ia melaju.
🗺️
Route ExplorerPenjelajah Rute
Browse all angkot routes overlaid on the map. Tap a route to see its full path, stops, and which vehicles are currently running it.
Jelajahi semua rute angkot yang ditampilkan di peta. Ketuk rute untuk melihat jalur lengkap, halte, dan kendaraan mana yang sedang beroperasi di rute tersebut.
🌧️
Weather-Aware TripsPerjalanan Berbasis Cuaca
Real-time weather data from OpenWeatherMap gives users trip suggestions based on current and upcoming conditions — especially useful during Medan's rainy season.
Data cuaca real-time dari OpenWeatherMap memberikan saran perjalanan berdasarkan kondisi saat ini dan mendatang — sangat berguna di musim hujan Medan.
🔔
Arrival EstimatesEstimasi Kedatangan
Distance and estimated arrival time calculated using OSRM routing, so passengers can plan their wait instead of guessing.
Jarak dan estimasi waktu kedatangan dihitung menggunakan routing OSRM, sehingga penumpang bisa merencanakan waktu tunggu tanpa perlu menebak-nebak.
📱
Driver ModeMode Pengemudi
A separate driver-side interface for angkot operators to broadcast their location, requiring minimal setup — just a phone with GPS.
Antarmuka khusus untuk pengemudi angkot agar bisa menyiarkan lokasi mereka, dengan pengaturan minimal — cukup sebuah ponsel ber-GPS.
☁️
Cloud DeployedDeploy di Cloud
Backend hosted on AWS EC2 with Nginx, accessible from anywhere in real-time. Designed to scale as more drivers and routes are added.
Backend di-hosting di AWS EC2 dengan Nginx, dapat diakses dari mana saja secara real-time. Dirancang untuk berkembang seiring bertambahnya pengemudi dan rute.
