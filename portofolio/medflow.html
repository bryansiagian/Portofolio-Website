Overview

What is MedFlow?

MedFlow is a real-time public transportation tracking system built for Medan, Indonesia's third-largest city. The app targets the city's angkot (minibus) network — a network that operates with no digital infrastructure, no schedules, and no predictability for daily commuters.

The system tracks vehicle locations live using GPS data fed through a Laravel REST API backend, visualized on a Flutter mobile app using Google Maps. Users can see which angkot is nearby, how far away it is, and which route it's running — information that simply didn't exist before in any accessible form.

Beyond tracking, MedFlow integrates real-time weather data from the OpenWeatherMap API to give trip recommendations. If it's raining heavily, the app can suggest alternatives or flag potential delays. The project was built for the Medan Coding Competition 2026, where it was awarded 2nd place.

Problem & Solution

The gap MedFlow fills.

⚠️
The Problem
  • Medan's angkot network has no digital presence — no app, no schedule, no real-time location data. Passengers wait with no idea when the next vehicle arrives.
  • Routes overlap and change informally, making it nearly impossible for newcomers or occasional riders to know which angkot to take.
  • No weather integration — commuters get caught off guard by Medan's sudden heavy rains, with no way to plan their route proactively.
  • Medan's Smart City aspirations lack a transportation layer. Without data, city planners can't optimize routes or understand demand patterns.
✦
Our Approach
  • Built a GPS-based vehicle tracking backend in Laravel that receives location updates from angkot driver devices and exposes them via REST API to the mobile app.
  • Designed a Flutter app with Google Maps integration showing live vehicle positions, route paths, and estimated arrival information.
  • Integrated OpenWeatherMap API to overlay current and forecasted weather on trip planning, so users can make informed decisions before leaving.
  • Used OpenStreetMap (OSM) and OSRM for open routing data, keeping the system independent of expensive proprietary map APIs for routing calculations.

Features

What the app does.

📍
Live Vehicle Tracking
See angkot positions updated in real-time on an interactive map. Know exactly where the nearest vehicle is and which direction it's heading.
🗺️
Route Explorer
Browse all angkot routes overlaid on the map. Tap a route to see its full path, stops, and which vehicles are currently running it.
🌧️
Weather-Aware Trips
Real-time weather data from OpenWeatherMap gives users trip suggestions based on current and upcoming conditions — especially useful during Medan's rainy season.
🔔
Arrival Estimates
Distance and estimated arrival time calculated using OSRM routing, so passengers can plan their wait instead of guessing.
📱
Driver Mode
A separate driver-side interface for angkot operators to broadcast their location, requiring minimal setup — just a phone with GPS.
☁️
Cloud Deployed
Backend hosted on AWS EC2 with Nginx, accessible from anywhere in real-time. Designed to scale as more drivers and routes are added.
